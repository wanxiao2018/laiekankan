# 去俄看看 · 圣彼得堡与莫斯科通用行程规划器

一个可以直接使用的静态旅行规划网站。包含圣彼得堡 17 个景点、9 处餐饮，以及莫斯科 14 个景点。两座城市可以切换，分别编辑、保存、分享和导出行程；路线不绑定任何节假日，出发日期可选。

## 打开

直接用浏览器打开 `index.html` 即可。也可在此目录运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

然后访问 http://127.0.0.1:4173 。不需要安装依赖。

可用 `?city=spb` 或 `?city=moscow` 直接进入对应城市。未指定城市时恢复上次选择。浏览器按地址与端口分别保存数据；继续编辑原行程时，请使用原来的预览地址。

## 已有功能

- 圣彼得堡 17 个景点的中文、俄语名称、地址、规划建议和来源入口。新增俄罗斯博物馆（米哈伊洛夫宫）、米哈伊洛夫花园及战神广场；后两处可作为博物馆或滴血教堂附近的步行停留。
- 莫斯科首批 14 个景点：红场、克里姆林宫、圣瓦西里大教堂、古姆、亚历山大花园、扎里亚季耶公园、特列季亚科夫老馆、老阿尔巴特、大剧院、高尔基公园、麻雀山、ВДНХ、莫斯科城及武装力量大教堂。场馆、街区和郊外景点的区别、入场提示、地址和来源写在详情里。
- 9 处餐饮：Porto 19、The Бык、Мясо & Хлеб、Столовая № 1、EUROSPAR、Илу、Теремок、Пышечная，以及 Булочная Ф. Вольчека 面包店。每条固定具体分店，附俄语地址、来源与核对日期。
- 分类与搜索，含常用中文别名；「吃什么」可筛选正餐、日常便餐、中餐、面包与早餐、甜点小吃。面包店选择涅瓦大街 15 号分店，适合市中心游览前的早餐或途中补给。
- 用餐点可放在当天第一站、指定地点之后或行程末尾；同一家店可安排在不同天，从某天移除不会影响其他天。景点保留原有跨天移动规则。
- 根据当天景点显示可选餐饮搭配；加入后同步更新编号、地图与导航。郊外单独游览日不推荐市中心餐厅为附近餐饮。
- Yandex 当天总览：地图标出全部景点与用餐点，地图下方的中文编号列表显示游览顺序；地图显示方式与每段交通选择独立。
- 地图与导航统一使用 Yandex：相邻景点逐段选择步行或公交／地铁。喀山教堂、书之家、滴血教堂等常见散步组合默认步行。
- 整天步行：可切换 Yandex 实际道路地图，并打开包含全部地点的步行导航。超过 8 站的长行程显示全天位置总览，并提供连续分组导航，每组最多 8 站，相邻组共用一站。
- 地图旁和行程栏均可切换天数；添加、移动、调序、删除和撤销会同步更新当天地图。
- 彼得堡参考路线控制在 3–5 日：3 日「市区精华」、4 日「市区与夏宫」、5 日「市区与双宫」，另有 5 日「艺术与花园」。艺术路线安排俄罗斯博物馆并保留一座郊外宫殿，海边与岛屿留在景点清单中供替换。选择路线时会显示对应安排说明；已有自定义行程仍可保留较长天数。莫斯科提供 2 日、3 日、5 日参考路线。
- 切换城市时同步更新景点清单、分类、地图、参考路线与资料来源；莫斯科暂专注景点，餐饮仍属于彼得堡。莫斯科提供 2 日、3 日、5 日和 6 日（含郊外大教堂）参考路线。两个城市的撤销记录在当前页面会话内独立维护。
- 当前浏览器保存行程、地图显示方式和逐段交通选择；导出带俄语地址、餐厅分店、资料来源及 Yandex 步行与公交链接的离线 HTML 手册。已有行程不重置，旧版公共交通与驾车模式迁移为位置总览，旧版步行地图保留。
- 出发日期可选；设置后每天显示对应日期，并随行程一起保存、分享和导出。分享链接使用 URL 片段编码当前城市、日期、地点顺序和交通选择，不读取本机其他数据；页面用本地脚本生成二维码，也支持复制链接或调用系统分享。若在 `file://` 或 `localhost` 本地预览，二维码只能用于当前设备环境；发布到 Pages 后需重新生成可供他人打开的二维码。
- 景点详情和导出手册增加门票／预约、开放／营业状态提示与官方入口。动态信息统一提示按具体出行日期确认，不把某个节假日当作默认场景。
- 手机、平板和桌面布局；手机提供景点与餐饮、地图、行程三个视图。

## 范围

这是可使用的静态旅行规划器，可部署到 GitHub Pages 等静态托管平台。当天总览、单个地点、整天步行与分段导航均采用 Yandex Maps。总览显示各站位置，步行模式中的紫色虚线由 Yandex 按实际道路计算。景点和餐饮坐标均附来源，核对记录见 `../research/地图与公共交通_2026-09-14.md` 和 `../research/餐饮核对_2026-09-14.md`。位置标记可能指向所在建筑，具体入口需在到达前确认。

新增彼得堡景点与莫斯科资料见 `../research/双城景点核对_2026-09-14.md`。克里姆林宫教堂广场与军械库入口不同；特列季亚科夫画廊定位拉夫鲁申斯基巷 10 号老馆；剧院按票面场馆安排。园区、街区和商务区的坐标表示所在区域，不能替代具体入场口。

`data.js` 与 `moscow-data.js` 分别提供两城数据。`planner.js` 保留原有彼得堡默认接口，并通过 `createFor(data)` 创建对应城市的规划逻辑。保存键分别为 `qu-ekankan-spb-plan-v1` 与 `qu-ekankan-moscow-plan-v1`；新增 `city` 标识，旧版无标识的彼得堡行程仍可恢复，其他城市的数据不会混入。切换时不把两城地点串成一天路线。

餐饮数据独立保存在 `food-data.js`。`pairWith` 用于按游览区域提供用餐搭配；`walkWith` 用于相近地点的步行初选。两者都不是实时路程或绕行时间估算。餐厅的 Yandex 位置链接采用店方提供的门店链接或固定坐标，嵌入地图固定具体分店的坐标，避免同名店、不同分店及异地同名搜索结果混淆。未加入实时评分、消费金额或营业状态。

Мясо & Хлеб 暂选 Киевская 街 5 号 корпус 6 店。瓦西里岛 9 线 16 号店在官网与第三方资料中存在营业信息冲突，因此没有纳入清单。Porto 19 官网在核对时列周一休息，详情提示按具体出行日期复查。

Yandex 路线链接明确使用 `rtt=pd`（步行）或 `rtt=mt`（公交／地铁），避免省略模式后恢复驾车。每段均可修改选择，打开 Yandex 后也能切换。步行初选依据两城景点及餐饮数据中的常见散步组合，不将坐标直线距离当作步行距离；其他组合先提供公交查询，不表示公交一定更快。单地点日打开 Yandex 位置页，由游客选择出发地和路线。

公共交通不发送多途经点，而是为每对相邻景点生成查询入口，保留完整顺序。网站不自行编造站点、车次、实时票价和总换乘时长；出发时间、站点和班次由地图服务查询。逐段选择按有方向的起终点保存，重排行程时不会把上一段的交通偏好套用到新路段。

地图使用 Yandex 官方公开挂件 `https://yandex.ru/map-widget/v1/`，当前无需配置 API key。单点与全天总览使用 `pt`（经度、纬度），多点之间用 `~` 分隔；`ll` 与带边距的 `spn` 覆盖当天全部地点。路线使用 `rtext`（纬度、经度）和明确的 `rtt`，保留站点顺序。`lang=ru_RU` 显示俄语地名并使用公制距离。接入核对见 `../research/Yandex地图接入_2026-09-14.md`。

公开挂件的图钉和控件由 Yandex 提供；自定义中文编号或地图标记与中文详情的双向联动需要进一步接入 JavaScript API。当前可通过地图下方的中文站点列表查看详情。挂件的加载和路由结果由 Yandex 提供，网站始终保留可直接打开的 Yandex 链接。

页面已停止加载 Leaflet 与 Google 地图，旧 `day-map.js` 已移除。`vendor/leaflet/` 中保留的旧版脚本、样式和许可证不再被页面引用。无需安装包或构建，也未加入地图瓦片离线下载。

地图需要网络。网站没有登录、云同步和行为统计。编辑结果保存在当前浏览器，跨设备可以查看导出的手册。参考路线未绑定具体日期，票价与营业时间未写死；演出场馆以票面信息为准。

景点和首批 6 个餐饮品牌来自用户列出的旅行清单，另补充俄式薄饼与本地小吃各一处，并按用户建议加入面包店；资料研究见 `../research/调研笔记_2026-09-13.md` 和餐饮核对记录。未将“寻找化石”路线纳入产品。

## 核心逻辑检查

```sh
node --test planner.test.cjs share.test.cjs qr.test.cjs
node --check app.js && node --check planner.js && node --check data.js && node --check moscow-data.js && node --check visit-data.js && node --check share.js
```

当前验证：38 项逻辑检查通过，覆盖两城参考路线、可选日期、城市数据隔离、Yandex 地图与路线、精确餐厅分店、长路线完整性、分享链接编码、本地二维码绘制、访问准备信息，以及离线手册导出。页面脚本语法检查也已通过。

Yandex 接入在独立的 4176 端口通过桌面 Chrome 操作验证：彼得堡三站位置总览与实际步行道路、调整地点顺序后 iframe 与整天链接同步更新、逐段切换公交后重开弹窗保留 `rtt=mt`。首次打开新端口、重载和切换城市均保留各自的本机行程。

在同源 iframe 的 390 × 844 CSS 像素视口内，已复查地图控件、中文站点列表与详情；切换莫斯科后，五站总览和整天步行均由 Yandex 成功加载。地图保持俄语地名和公制距离。临时检查页面已移除。真实手机的触控、地图应用唤起和网络体验尚待验证。

原有 4173、4174、4175 的用户行程不用于测试修改。早期地图供应商的检查记录保留在历史研究笔记中，当前实现以本节和 Yandex 接入记录为准。
